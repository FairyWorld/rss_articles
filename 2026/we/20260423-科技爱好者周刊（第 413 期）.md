## 如果人类文明停留在21世纪初

最近看到[一篇文章](https://lukaszkups.net/notes/early-2000s-were-peak-of-humanity/)，作者感叹，要是人类文明停留在21世纪初的水平，不再向前发展，那该多好。

具体来说，就是停留在2007年6月29日之前。那是 iPhone 诞生的日子。作者的意思是，如果人类没有进入智能手机时代，保持那一时刻的科技水平，就很完美。

> "我真心认为，21世纪初可能是人类最接近科技与生活完美平衡的时期。
>
> 我们拥有足够的技术来让我们的生活更轻松，但技术还不足以让人感到担心。"

那时，手机只有部分智能功能，可以打电话、发短信、玩小游戏，有一个很烂的摄像头，基本上就是这样了。

互联网早已存在，可以搜索信息、发送电子邮件、下载音乐、与人聊天。但它不在你的口袋里，让你每隔37秒就查看一次。

那时，技术只是一种工具，不是一种生活方式。

那时，世界依然还是实体的，音乐保存在 CD，电影保存在 DVD，必须通过播放器播放。拍照需要相机，跟人聊天需要打电话，想知道朋友在干嘛，就要去问他们，想认识某人，就要去见面。

科技主要起到的是辅助真实世界的作用，而不是建立虚拟世界，试图取代真实世界。

那时，互联网只是一个去处而已。你坐在电脑前上网，完成任务后，你就下网。你不会永远在线，不像现在，你会发现自己时时刻刻在线，在网上工作，一边吃饭一边看视频，一边走路一边网上的音乐，然后一边上网一边就睡着了。

如果你现在有十分钟什么事情都不做，你就会问自己：“哪里出了什么事情？”

那时有论坛，有网上聊天，你仍然可能会花费太多时间与网上的陌生人聊天。不同之处在于，互联网不是你全部的社交，你可以在网上消失三个月，没人指望你发布关于自己的最新动态，也没有算法来判断你这个人是否有趣。

那时，做什么事情都没有那么方便，你无法完全依靠互联网去完成，很多事情还是必须自己亲自去做。

后来我们不再问这个问题了：“技术如何让这一切变得更简单？”

而是开始问：“技术如何完成它？”

你想购物？你需要一款 App。

你需要地图？你需要一款 App。

你想约会？你需要一款 App。

你需要朋友？你需要一款 App。

你的回忆都变成了云存储，你的对话都变成了即时通话，你的注意力都被无限滚动消耗了。

我们不断地为那些原本运行良好的事物创建数字副本。

技术确实让我们的生活变得更便捷，但是也因为成为了我们生活的中心。

如今，你想要更多的生活，就只有更多参与数字化，再装更多的 App。

虽然科技让我们的生活变得更方便，提供更多可能性，我们回首才发现，曾经的生活是如此不同。虽然没有那么方便，但是在那时，我们也可以快乐地生活。

人类的最佳生活时期，会不会就在刚刚过去的21世纪初：足够现代化，足够便利，但又不是那么现代化，那么便利。你无需时刻接触科技，也能体验到科技带来的好处。生活的大部分没有被数字化，这也意味着很多事情你通过互联网做不到，不得不亲自去做。

虽然那时的生活还有很多糟糕的部分，比如网速很慢，还有 Flash 和 Internet Explorer。

我们会毫不犹豫选择更便捷、更科技的生活，但回过头却发现缓慢生活和不便利，也有让人怀念一面。

希望2007年开始的智能手机革命，2022年开始的 AI 革命，能把我们带到一个更好的地方。


## AI 会让所有的东西短缺吗？

https://out-of-hell.xylon.me.uk/shortage.html

AI 已经让内存、闪存、硬盘出现了短缺。在美国，燃气轮机和其他发电设备的成本，也翻了一翻。

工厂厂房被分配给 AI，比如汽车工厂开始改造成服务器工厂。

未来如果人形机器人开始大规模生产，那么我认为，短缺问题可能会蔓延到几乎设备。

假设现在全世界突然需要大量机器人，那么不转型生产机器人（或机器人零件）就太愚蠢了，利润率会高得多。

即使是那些继续生产汽车的公司，其零部件成本也会更高，因为它们将面临铜、铝、锂离子电池等原材料的竞争。

所以我预测，未来十年，几乎所有制成品的价格都会飙升。从汽车到微波炉再到洗衣机，无一例外。

以市值来看，全球市值最高的公司是英伟达（NVIDIA），市值达 5.5 万亿美元，该公司主要生产人工智能硬件。排名第二的是苹果公司，市值达 4.7 万亿美元，该公司主要生产面向人类的硬件。

我认为我们需要为这样一个世界做好准备：大部分经济活动都服务于人工智能，而人类在市场中所占的比例相对较小。

传统企业很可能代表人工智能的利益。一群超级智能人工智能控制着一家雇佣人类并操控众多机器的公司。

## 世界地图的新投影方法

上周发生了一件大事，联合国投票决定[废除](https://www.not-ship.com/united-nations-map/)墨卡托投影。

我们知道，地球是圆的，地图是平的。这注定了必须采用某种转化方法，将圆形地貌投影到平面地图上。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026091304.webp)

上面是目前通行的世界地图，采用了墨卡托投影。

这种投影相当于把地球仪拉伸为矩形，直接后果就是高纬度地区会被极大拉伸，看上去面积偏大。

上图中，赤道的非洲看上去跟高纬度的格陵兰岛一样大小。实际上，前者的面积是后者的14倍。

联合国建议，废除墨卡托投影，**采用新的平等投影法绘制世界地图**。

这种投影法的核心原则是不改变面积比例。如果一块土地占地球面积1%，那么它占地图面积也应该是1%。它会根据面积进行适度拉伸。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026091305.webp)

上图就是平等投影法的世界地图，非洲变大了。

下面是墨卡托投影和平等投影的欧洲和非洲。大家可以比较差异。

## 再见了，React Native

Spotify [宣布](https://shopify.engineering/back-to-native)，放弃 React Native，改用 Swift 和 Kotlin 开发它的移动版。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026091307.webp)

也就是说，它决定采用原生语言，开发 iOS 和安卓客户端，不再采用 Web 技术开发一个中间版本，再编译成各平台的客户端。

2020年，Spotify [决定](https://shopify.engineering/react-native-future-mobile-shopify)全面转向 React Native，拥抱 Web 技术。当时，这是一个大新闻，它说了三个理由。

> - 不用为每个平台重复开发相同的功能。
> - 允许开发人员跨技术栈工作。
> - 多出现的时间和精力，可以用来创造更多的价值。

上面这些当然都是场面话，真正的理由只有一个：省钱。

使用 React Native 可以只养一个团队，比起安卓和 iOS 要养两个团队，可以大大节省成本。

正是这种成本思维，同样导致它如今放弃 React Native。因为现在有了 AI，代码可以让 AI 转换，不需要中间版本了。

直接让 AI 把 Kotlin 代码翻译成 Swift 代码，几乎没有成本，性能还比 React Native 更好，何乐而不为呢。

当然，React Native 本身也是不争气，自从2015年发布，已经超过10年，一些基本的技术问题至今没有解决，使用起来也不便捷，被别人替代，一点也不冤。

总之，AI 出现之后，相当于一个无所不能的自动翻译器，像 React Native 这种中间语言或者兼容层，完全丧失了市场，退出历史舞台成了必然的命运。。

## 糊状千层面

让我们实话实说，大多数人的代码都是垃圾代码。

但是，垃圾也是分等级的。它可能意大利面条式代码（Spaghetti code），乱成一团，根本理不清楚。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026090704.webp)

也可能是“[糊状千层面式代码](https://underreacted.leaflet.pub/3mdjygm2p5s2c)”（slop lasagna）。也是糊在一起，但分成了很多层，至少可以按着层把它分开。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026090703.webp)

**你的代码应该避免成为意大利面，宁可成为千层面**。

React 框架的一个好处就是，它把代码拆分成组件，这样设计的好处就是垃圾代码变成了一个个可单独替换的“盒子”。

删除组件、复制组件、内联组件、重写组件都是很容易的操作。它让你只需关注组件的内部代码。

只要你的组件树设计是合理的，那么每个组件内部的具体代码就无关紧要。最糟糕的情况是，某人写了一个10000行的垃圾组件，但哪有什么关系呢，最终有人会重写它，它影响不到代码库的其他部分。

**只要代码是千层面结构，那么单独一层很糟糕，并不影响全局**。

真正重要的是下面的事情。

（1）数据如何在系统中流动，当前的数据来自哪里的输入，又输出了什么，以及你存储了哪些数据。

（2）用户体验如何，有没有明显的漏洞、糟糕的性能和前后不一致的行为。

（3）基本的抽象概念是否正确，有没有误用。

**只要上面三点 OK ，代码又是组件式的可抽换结构，那么程序就没有大的问题**。这时，代码是否冗长、写得好不好、是否简洁合理，有没有小 Bug，其实无关大局。

1、[隐藏摄像头检测器](https://www.chosun.com/english/industry-en/2026/08/30/SBFXUIJQYZEARKP5T4FBAY25HQ/)

韩国科学家发明了一种装置，可以快速检测周围有没有隐藏的摄像头。

这种装置就是一块电路板，上面有多个发光二极管，会依次点亮，连接手机即可使用，造价很低。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026090101.webp)

它的原理是，发光二极管发出的光，会被隐藏的摄像头反射。只要从接收到的反射光里面，排除正常的镜面，就可以确定摄像头的位置。

那么，如何才能排除其他的反射光呢？这个装置用了一个很巧妙的办法，就是依次亮起不同位置的发光二极管。

其他的镜面都是平面，摄像头的镜面是透镜，反射光会出现位置偏移。利用不同的光源，就可以确定发生偏移的反射来自何方。

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026090102.webp)

1、[风力发电机的木质基座](https://www.bbc.com/news/science-environment-67718719)

为了获得更大的发电功率，风力发电机越造越大。

目前，风力发电机的基座都是圆柱形钢塔。随着它的直径和高度的增长，运输和架设难度快速上升。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023123009.jpeg)

一家瑞典公司最近推出了一个新方案：使用木板建造风力发电机的基座。

他们将多层木材粘合并压缩在一起，形成圆弧状。然后将这些部件带到工地，粘合成一个圆柱体，堆叠成塔。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023123010.webp)

这样的好处就是，基座的重量大大减轻，并且可以分块安装，使得运输和架设变得容易。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023123011.webp)

走进基座的内部，可以清晰地看到墙壁的木质纹理。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023123012.webp)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023123013.webp)

如果这种木板被证实，可以胜任风力发电机的基座，具有足够的强度，并且能够防火。那么，它就也可以用来建造高层建筑，具有广阔的前景。

## 文摘


1、[工程师如何建造东西](https://adapt.com/blog/build-wide-ship-narrow)

优秀工程师会在开发之前做好规划：先写一份功能需求文档（RFC）来描述功能，然后将其拆分成更小的任务，再逐个开发。

编写任何一行代码之前，整个工作流程就已经确定了。

这个流程很合理，但它要求你在对问题了解最少的时候做出最关键的结构性决策。

在动手搭建任何东西之前，你都在猜测：哪些部件可以拆卸，每个部件的复杂程度如何。有时你的猜测是对的，但通常情况下，你的猜测是错的，前一步最终会被抛弃。

这种试错并不是白白付出代价：在搭建过程中，你可以学到东西，如果一开始你规划了一个错误的架构，然后动手实现这个错误的架构，这很可能让你学得更快。

1、[采浆果](https://www.tsoon.com/posts/picking-berries-meditation/)


我家有一个果园，我经常去采浆果。

![](https://cdn.beekka.com/blogimg/asset/202608/bg2026081602.webp)

我发现，随着年龄增长，我对这件事的态度发生了变化。

十几岁的时候，我特别讨厌采浆果。那时，我喜欢和人交往，每次妈妈让我去摘，我都特别不想去，感觉像是被迫去做苦差事，让我无法去做自己真正想做的事——和朋友们在一起，和别人相处。

当我在户外开始采时，思绪总是飘忽不定，边摘边吃。我只是把它当作工作，从不在意周围，只想着早点把活干完。

成年后，情况发生了变化，我开始喜欢采浆果。因为平时的事情很多，我需要一些独处、安静的时刻来认真思考。每到假期，我都特意安排时间去采浆果。如果错过了，我会非常想念它。

采浆果时，周围变得安静，平静。这时，我才真正开始仔细观察鸟儿。幼鸟们还在学习飞行，充满好奇地飞近我、打量我，鸟爸鸟妈则退到远处，更加谨慎，鸣叫着警告雏鸟，提醒它们注意这个生物。

现在，我对外界的兴趣变小了，各种想法越来越少，需要思考的新事物也越来越少。采浆果时，我不再想任何事，只有手中酸甜的浆果、周围的鸟儿、头顶的天空。无需思考，无需琢磨。只是静静地待在那里。
